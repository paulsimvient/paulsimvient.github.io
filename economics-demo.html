What this page runs

Named policy

bid = 75 + 5·H + 3·N + 12·H·N + ε. Every displayed number comes from this function under seed 42.

Matched ε

Each draw index i reuses the same ε for all four information cells so contrasts cancel shared noise.

Sealed holdout

Discovery uses three cells. Positive news · rising stays sealed until freeze; then observed mean is compared to additive ($83) and interaction predictions.
